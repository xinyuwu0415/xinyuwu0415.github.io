
# xinyuwu0415.github.io

This is the personal academic homepage of Xin Yu Wu.

## How to Deploy

1. Create a GitHub repository named:

xinyuwu0415.github.io

2. Upload all files in this folder to the repository.

3. Go to:

Settings → Pages

4. Choose:

Deploy from a branch

5. Select:

main / root

6. Visit:

https://xinyuwu0415.github.io

## How to Edit

You only need to edit:

index.md

using Markdown syntax.

No HTML knowledge required.
