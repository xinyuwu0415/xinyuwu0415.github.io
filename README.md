# Xin Yu Wu Academic Homepage

This is a static GitHub Pages academic homepage generated from the CV.

## How to publish

1. Create a new GitHub repository named `YOUR_GITHUB_USERNAME.github.io`.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`, then save.
6. Visit `https://YOUR_GITHUB_USERNAME.github.io/` after GitHub finishes deployment.

## Files

- `index.html`: homepage content and structure.
- `styles.css`: visual style.
- `script.js`: interactive research map.
- `assets/`: put your profile photo and CV PDF here if needed.

## Suggested edits

- Replace placeholder profile links in `index.html` with Google Scholar, ORCID, ResearchGate, and IEEE links.
- Replace the `XW` avatar block with your real photo if desired.
- Add paper links or DOI links to the publication list.
- Edit `script.js` to add more research or conference locations.
